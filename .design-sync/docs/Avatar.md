# Avatar

Round avatar with image and initials fallback.

- `size="sm" | "default" | "lg"`; `AvatarImage` + `AvatarFallback` (initials, uppercase). `AvatarBadge` adds a status dot, `AvatarGroup` + `AvatarGroupCount` stack several.

Source: `takussan-web/src/components/ui/avatar.tsx`.
