# Tooltip

Short text that explains a control already named on screen, shown on hover and keyboard focus.

- `TooltipTrigger` takes the control through `render`; `TooltipContent` takes `side`, `align` and `sideOffset`.
- Never the only place a needed piece of information lives: a tooltip does not open on touch.

Source: `takussan-web/src/components/ui/tooltip.tsx`.
