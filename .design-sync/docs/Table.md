# Table

Data table for the app consoles: hairline rows, muted hover, horizontal scroll inside its container.

- `Table` › `TableHeader` › `TableRow` › `TableHead`, `TableBody` › `TableRow` › `TableCell`, optional `TableCaption` / `TableFooter`. Amounts in `tabular-nums`.
- In the sidebar shells a wide table scrolls (`overflow-x-auto`), never clips.

Source: `takussan-web/src/components/ui/table.tsx`.
