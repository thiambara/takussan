# DropdownMenu

Menu of actions attached to a trigger (account menu, row actions).

- `DropdownMenuTrigger render={<Button variant="outline"/>}`, then `DropdownMenuContent` with `DropdownMenuLabel`, `DropdownMenuItem`s (lucide icon first) and `DropdownMenuSeparator`.
- Put destructive items last, after a separator.

Source: `takussan-web/src/components/ui/dropdown-menu.tsx`.
